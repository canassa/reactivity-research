# 2026-10-16: tea-local, the first prototype strategy

## Done

- `frameworks/tea-local/`: a plain Vite 8.3.4 build (no plugin, same rolldown as Solid), a small
  runtime (DOM helpers that skip unchanged writes, microtask batching, instances, keyed list) and
  Solid 2's `reconcileArrays`, vendored from beni's rendering-design research (strategy C).
- `scenarios/dashboard/tea-local.js`: one module per widget kind (message tags, reducer, DOM
  factory), one config plus one factory call per widget. Summaries watch their sources;
  `tick`/`notify` are clock and feed messages; `serverSet`/`snapshot` replace models.
- `./rr check` passes at N = 1, 4, 16, 64, 128 and 256, seeds 1–3. Builds are byte-identical.

## Learned

- **Measured (not committed, for the owner's consolidated report):** at N = 1, 1153 B brotli
  against Solid's 6583 B. Slope at N ≥ 16: 29.1 B/widget against Solid's 28.1. The app code is
  almost the same size as Solid's at every N. The gap is the runtime: 1.26 kB against 6.5 kB.
- Sharing one factory per kind is what keeps the slope at Solid's level, as beni's PR predicted.
- Comparing against the DOM's current value is enough to skip writes. A number input needs a
  numeric comparison (`valueAsNumber`), or "1.50" would be rewritten to "1.5" while typing.
