# 2026-10-16: beni, on browser-tea and browser-direct

## Done

- Pinned beni at `6a1b567fa` (its `origin/master` today) and built it with its own flake and
  `zig build -Doptimize=ReleaseFast` (`frameworks/beni/install.sh`; build id
  `ee040d874c1f0f73e43a0e7ef109007d`). The user's beni checkout is untouched.
- `frameworks/beni/`: what both setups share (build helper, page, adapter, the project's
  platform layer `Push.beni`), linked into `frameworks/beni-tea/` and `frameworks/beni-direct/`
  so both measurement hashes cover it.
- One beni source for both platforms (`scenarios/dashboard/shared/beni.js`, the scenario's new
  shared folder): one module per widget kind, `Main` with per-widget
  `Config` data, `Tea.element`, keyed `For`, a `schema` declaration for the pushed events. Every
  module matches `beni fmt` exactly.
- `./rr check` passes on both at N = 1, 4, 16, 64, seeds 1–3; builds are byte-identical and run
  offline. `runs.json`: beni-tea at 1–256, beni-direct at 1–128.

## Learned

- **Measured (not committed):** N=1 totals 9 298 B (tea) and 10 091 B (direct), against Elm's
  6 851 and Solid's 6 583. Slopes at N ≥ 16: 91.4 B/widget (tea, to 256) and 144.2 (direct, to
  128), against Elm's 52.2 and Solid's 28.1. `Tea.element` (the only way to subscribe to the
  host) brings the fiber runtime, `Dict` and part of `Schema`: about 7.9 kB of runtime at N=1.
  Direct compiles each widget instance's handlers and writes separately: `Main` is 142 kB raw at
  N=64 against 36 kB on tea.
- beni has no ports: host input goes through a project platform layered on the shipped one, a
  `Sub.on` over a `window` event. It has no unmount either (`boundary.md` §9.8.14, W51): the
  adapter removes the listeners the program added to `window` and `document` itself.
- Inputs are controlled: a value the model does not hold is put back, so the amount widget keeps
  its typed text in the model. `String.fromFloat 85` is `"85.0"`. A clicked checkbox is put back
  by a zero-delay timeout, which `settled` waits for.
- browser-direct's ownership checker shapes the source: lists from the host need `List.copy`,
  and the event must be decoded in `update`. Its 64-path width cap refuses the N=256 app (every
  seed) and some mid sizes (N = 70–88 for seed 1).
- The harness's static server has no `.mjs` type, so the build serves beni's module as `_main.js`.
